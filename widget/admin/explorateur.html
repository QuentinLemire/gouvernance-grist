Colonne de gauche : les pages du document (organisées selon la même hiérarchie que le panneau de pages de Grist, d'après _grist_Pages) et les widgets (vues) qu'elles contiennent — les traits en pointillés gris relient une page à ses sous-pages. Colonne de droite : les tables sources du document. Chaque trait coloré relie un widget à la table qu'il affiche (tableRef de la section). Pour les widgets personnalisés (Custom widget builder ou URL externe), des traits gris en pointillés relient en plus le widget aux autres tables que son code utilise réellement (détectées via grist.docApi.fetchTable(...) / grist.onRecords(...), comme dans l'onglet « 🧱 Custom widgets »).
